## 這是什麼？

你從 **16 歲的高中舞社** 開始，一路經歷公開徵選、練習生、職業合約、隊內排位競爭、
季後賽、跨運動兼任、海外挑戰、副業經營、身心崩潰與世代交替，最後決定要用什麼姿態離開舞台。

- 起始：**16 歲・2026 年**
- 上限：**42 歲**（最長 78 個決策階段）
- 每一次選擇都不可回溯，**相同種子 + 相同選擇 = 完全相同的一生**

## ✨ 核心特色

### 🎲 命運不可預覽
種子等級（💀 苦命 / ⚪ 平凡 / 🌟 天才 / 💎 神童 / 👑 百年一遇）只在開局後的**天賦鑑定畫面**才揭示，
六軸資質數值預設隱藏，需要靠訓練撞牆、運動科學檢測或拜師才能逐步解鎖。

### 💠 努力可以逆天
屬性練到資質天花板後不再浪費行動點，改為累積「**鑽研**」進度，填滿即可把上限往上推（絕對上限 92）。
**💀 苦命種子的鑽研次數與門檻減免最多** —— 這是專為「用時間換天賦」設計的路線，並獨佔 5 個成就。

### ⚖️ 取捨大於堆疊
行動點與休賽期檔期雙重稀缺、專注連段與全能連段互斥、兼任兩隊必付代價、副業越多收益越遞減。
沒有「全部都要」的最佳解。

### 🌟 你不是唯一一個在練的人
每年重算隊內排位（C 位 / 前排 / 後排），還有一位**會逐年變強、34 歲才引退的同期對手**擋在 C 位前面。

### 🚨 壓力不是只有歸零才死
壓力爆表會觸發「**壓力三振**」：第一次醫囑休養、第二次留下慢性壓力、第三次醫生禁止上場強制引退。

### 🏆 可分享的故事
極品與極廢種子皆有獨立敘事與稱號；**48 項成就 + 14 項隱藏目標**跨生涯永久收集，
結算可輸出隊伍配色的 PNG 生涯卡片並直接系統分享。

## 🎮 怎麼玩

### 年度三階段循環

```
季初（規劃）  → 消耗行動點：六維訓練 / 鑽研 / 休養 / 諮商 / 投資
賽季中（舞台）→ 抽取 2~4 個事件做選擇；達標則進入季後賽流程
季末（總結）  → 年度收入結算 → 崩潰判定 → 合約談判 → 休賽期檔期規劃
```

### 六大屬性

| 屬性 | OVR 權重 | 主要用途 |
|---|---|---|
| 💃 舞蹈 | 0.24 | Solo / C 位 / 對決 / 徵選複選 |
| ⭐ 魅力 | 0.20 | 代言 / 試鏡 / 紅毯 / 徵選初選 |
| 🏃 體能 | 0.17 | 冠軍戰 / 行動點加成 / 趕場 |
| 📱 社群 | 0.16 | 提案 / 電商 / 副業 / 澄清 |
| 🎤 主持 | 0.13 | MC / 隊長選舉 / 公關危機 |
| 🤸 特技 | 0.10 | 空翻 / 疊人塔 / 海外交流 |

### 新手三個建議

1. **前 4 年別亂花行動點** —— 20 歲前的「早熟」加成不會回來。
2. **壓力比疲勞可怕** —— 疲勞會自動恢復，壓力會累積成永久債。
3. **簽約前先看門檻減免** —— 口碑、冠軍、海外經歷、語言能力都能把門檻往下拉。

## 🛠 技術架構

| 項目 | 內容 |
|---|---|
| 架構 | **單一 HTML 檔案**，HTML + CSS + Vanilla JS |
| 外部依賴 | **無**（僅一支網站流量計數 script，可移除） |
| 建置流程 | **無需編譯**、無 npm、無 bundler |
| 資料儲存 | `localStorage`（全部在你的瀏覽器，不上傳任何伺服器） |
| 亂數 | `mulberry32` PRNG，字串 hash 種子 → 完全可重現 |
| 圖形 | Canvas 繪製生涯卡片；SVG 雷達圖與環形進度 |
| 設計取向 | 手機優先（安全區域適配、觸控區 ≥52px），≥900px 切換桌機雙欄 |
| 無障礙 | `role="progressbar"` / `aria-live` / `radiogroup` / `noscript` |

### 儲存的資料

| localStorage 鍵 | 內容 | 生命週期 |
|---|---|---|
| `CheerLife_SaveT` | 當前生涯存檔（`VER 110`） | 引退後自動清除 |
| `CheerLife_Hall` | 跨生涯成就殿堂 | **永久保留**（可手動清除） |
| `CheerLife_LastSeed` | 上一局種子（避免連續重複） | 覆寫 |

> 🔒 **隱私**：本作沒有帳號系統、沒有後端、不收集任何個人資料。
> 所有進度僅存在你自己的瀏覽器；清除瀏覽器資料會一併清除存檔。

## 🚀 本機執行

不需要任何工具，直接開檔即可：

```bash
git clone https://github.com/你的帳號/cheerlife.git
cd cheerlife
open index.html          # macOS
# start index.html       # Windows
```

若要避免瀏覽器對本機檔案的限制，可起一個簡易伺服器：

```bash
python3 -m http.server 8080
# 然後開 http://localhost:8080
```

### 開發者工具

在網址後加上 `#dev` 進入事件檢查模式，會執行 `validateEvents()`：

```
http://localhost:8080/#dev
```

檢查項目：事件 id 重複、缺少 `where` / `cd`、選項數 < 2、`title` / `ch` 執行失敗、
徵選 / 兼任 / 隊內定位是否正確 gate、學生階段是否誤含職業內容、成就 id 重複，
並輸出事件與成就總數。
